# Health Codex

Приложение демонстрирует раздел «Профиль» для медицинских данных пациента на базе Kotlin, Jetpack Compose, Room и DataStore.

## Возможности профиля

- Хранение расширенной медицинской информации: личные данные, диагнозы, аллергии, медикаменты, пороги для сердечных показателей.
- Списки диагноза/аллергий/медикаментов редактируются прямо на экране с подсказками валидации.
- Экспорт профиля в JSON (каталог Documents) и импорт последнего сохранённого файла.
- Генерация и расшаривание ICE-карты (информация для экстренных служб).
- Привязка BLE-устройства (заглушка со списком примерных девайсов).
- Настройки безопасности: биометрическая защита, разрешение HTTP, демо-режим измерений.

## Биометрия и защита

Включить защиту можно в разделе «Безопасность профиля». При активации флаг сохраняется в DataStore, экран профиля готов к интеграции с `BiometricPrompt` (поведение можно расширить в `ProfileSecurityRoute`).

## Экспорт и импорт

- Экспорт создаёт JSON-файл `HealthProfile_YYYY-MM-DD.json` в системном каталоге Documents (через `MediaStore`).
- Импорт ищет последний сохранённый файл `HealthProfile_*` и подгружает данные в форму редактирования.

## Тесты

`./gradlew test` запускает unit-тесты для валидации и JSON-сериализации профиля.

## Работа с ветками

В репозитории основная ветка разработки называется `implement-profile-section-with-jetpack-compose`. Если в списке веток Android Studio вы видите вариант с префиксом `codex/implement-profile-section-with-jetpack-compose` (как на скриншоте ниже), выбирайте именно его:

1. Откройте **Git** → **Fetch**, чтобы обновить список удалённых веток.
2. В выпадающем меню веток в блоке **Remote** выберите `codex/implement-profile-section-with-jetpack-compose` и нажмите **Checkout**.
3. Когда Android Studio предложит создать локальную ветку, оставьте имя `implement-profile-section-with-jetpack-compose` и подтвердите переключение — после этого появится локальная ветка в блоке **Local**.
4. Работайте в локальной ветке `implement-profile-section-with-jetpack-compose`: она содержит все изменения раздела «Профиль».

> Если вместо префикса `codex/` отображается `origin/`, выполните те же действия — это зависит только от имени удалённого репозитория, к которому вы подключены.
