# Home UI Package

Этот пакет предназначен для расширения проекта "Здоровье" визуальными и кодовыми артефактами. Из-за ограничений среды выполнения в репозитории отсутствуют бинарные файлы (Figma, PNG, ZIP). Вместо этого предоставлены структуру каталогов, описания и Flutter-скелет.

## Содержимое
- `figma/` — поместите сюда исходный `.fig` или ссылку на проект Figma. Создайте страницы: Design System, Home - Light, Home - Dark, Home - Tablet, Photo Mockups - Desk, Photo Mockups - Hand.
- `assets/icons_svg/` — экспортируйте сюда иконки (filled/outline) со свойством `fill="currentColor"` или `stroke` для outline.
- `assets/icons_png/` — PNG-версии иконок в размерах 48, 72, 96, 144, 192 px.
- `mockups/` — экспорт фотореалистичных мокапов в PNG 3000–4000 px (сцены: телефон на столе с ковриком Yin-Yang и телефон в руке).
- `flutter/` — пример Flutter-приложения с главной страницей, повторяющей гибридный макет.

## Инструкции
1. Воссоздайте макет в Figma, используя предоставленные стили и текстовые строки (см. `lib/strings.dart`).
2. Экспортируйте иконки, соблюдая размеры и требования к `currentColor`.
3. Снимите/сгенерируйте мокапы, убедившись, что устройство — Android без iOS-элементов, а статус-бар соответствует описанию.
4. Упакуйте всё в `home-ui-package.zip` со структурой из требования.
5. Обновите README с реальными ссылками после генерации ассетов.

## Flutter-сборка
Скелет Flutter находится в `flutter/lib`. Он демонстрирует:
- гибридную сетку 2×2 и список карточек;
- навигацию к деталям метрик с Hero-анимацией;
- заглушки для графиков и shimmer-эффекта;
- локализованные строки на русском языке.

### Запуск
```bash
flutter pub get
flutter run
```

## Замечание
Вся текстовая информация в макетах должна оставаться векторной. Используйте шрифт Roboto с полной поддержкой кириллицы.
